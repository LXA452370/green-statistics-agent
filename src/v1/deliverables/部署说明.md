# 部署说明：把「绿账本」变成一个老师能点开的网址

> 这个作品是**纯静态网页**（HTML + CSS + JS，零依赖），所以部署 = 把 `绿账本_在线智能体/` 这个文件夹原样传上去。
> 不需要服务器、不需要数据库、不需要 Node 环境，也不需要 API Key。

---

## 0. 先明确一件事

**"在线链接"这一步必须由你们自己完成**，因为注册账号需要你们的邮箱 / 手机 / 实名验证，我无法代劳。
下面的步骤都控制在 5–10 分钟内。

> 交付物里已经准备好：`绿账本_部署包.zip`（内容就是站点文件，可直接拖到托管平台）。
> **注意**：解压后根目录必须直接是 `index.html`，不要多套一层文件夹。

---

## 1. 推荐方案 A：Cloudflare Pages（免费、免备案、速度尚可）

1. 打开 https://dash.cloudflare.com/sign-up ，用邮箱注册并验证（2 分钟）。
2. 左侧菜单选 **Workers & Pages → Create → Pages → Upload assets**。
3. 项目名填 `greenledger`（会变成网址的一部分，全小写、无中文）。
4. 把 `绿账本_在线智能体` 文件夹里的**所有文件**拖进上传区（或上传 `绿账本_部署包.zip`）。
5. 点 **Deploy site**，等 10–30 秒，得到形如
   `https://greenledger.pages.dev` 的网址。
6. 打开这个网址，按下面第 5 节验收。

**优点**：免费额度足够、支持自定义域名、可随时重新上传覆盖。
**注意**：首次访问可能稍慢（境外节点），建议在教室网络里提前打开一次。

---

## 2. 备选方案 B：Netlify Drop（最快，拖拽即得）

1. 打开 https://app.netlify.com/drop ，用 GitHub 或邮箱登录。
2. 把 `绿账本_在线智能体` 文件夹直接拖进页面。
3. 得到形如 `https://random-name-123.netlify.app` 的网址。
4. 想改名字：Site settings → Change site name → `greenledger-2026`。

**注意**：免费站点长期无访问可能休眠，**提交前一周内至少访问一次**；必要时在截止前重新部署一次保持活跃。

---

## 3. 备选方案 C：GitHub Pages（如果你们已经有 GitHub 账号）

```bash
# 在仓库根目录
git init
git add .
git commit -m "greenledger v1.0"
git branch -M main
git remote add origin https://github.com/<你的账号>/greenledger.git
git push -u origin main
```
仓库 → Settings → Pages → Source 选 `main` / `root` → Save。
约 1 分钟后得到 `https://<账号>.github.io/greenledger/`。

**注意**：如果仓库名不是 `greenledger`，链接会带仓库名；仓库必须是 **Public**。

---

## 4. 备选方案 D：学校服务器 / 已有域名（最稳，若有条件）

1. 把文件夹上传到服务器的静态目录，例如 `/var/www/greenledger/`。
2. Nginx 配一个 location 指向该目录；或临时用：
   ```bash
   cd /var/www/greenledger && python3 -m http.server 8080
   ```
3. 让老师通过 `http://<学校域名或公网IP>:8080/` 访问（需网络可达）。

**提醒**：用公网 IP + 端口访问时，先确认学校防火墙放行；国内域名需备案。

---

## 5. 部署后必须做的验收（5 项，缺一不可）

| # | 检查 | 怎么做 | 通过标准 |
| --- | --- | --- | --- |
| 1 | 无痕窗口打开 | Ctrl+Shift+N 粘贴链接 | 页面正常，无需登录 |
| 2 | 跑完整流程 | 点「02 脏数据样例」→ 确认执行 → 生成报告 | 40 秒内出报告，无报错 |
| 3 | 换页面 | 点顶部「工作流说明」「关于与口径」 | 流程图与表格正常显示 |
| 4 | 下载功能 | 点「下载清洗后 CSV」「下载 Markdown」 | 两个文件都能下载并打开 |
| 5 | 手机打开 | 用手机浏览器访问同一链接 | 布局不错乱、能点开示例 |

**另外**：把链接发给组外一位同学，让他独立走一遍——他能走通，老师就能走通。

---

## 6. 常见问题

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 打开是文件列表 / 404 | 站点根目录不是 index.html（多套了一层文件夹） | 重新上传，确保 `index.html` 在根目录 |
| 页面空白、样式丢失 | 上传时漏了 `assets/` 目录 | 整个文件夹一起传，或在 zip 中确认 assets 存在 |
| 流程图不显示 | `assets/workflow.svg` 未上传 | 单独补传该文件 |
| 上传 Excel 报"解析失败" | 文件是旧版 .xls，或表格有合并单元格 | 另存为 .xlsx / .csv；取消合并单元格 |
| 国外平台访问慢 | 节点在境外 | 提前在教室网络测试；必要时改国内对象存储（需备案） |
| 平台提示站点休眠 | 免费套餐长期无访问 | 提交前一周访问两次；或重新部署 |

## 7. 链接的三种"交付形态"（按作业要求准备）

1. **主链接**：部署得到的网址，写入 `01_在线体验链接.txt`、README 与设计报告。
2. **备用链接**：在第二个平台再传一份（例如 Cloudflare + Netlify 各一份），主链接打不开时可用。
3. **免部署兜底**：随包提供的 `绿账本_在线智能体` 文件夹，双击 `index.html` 即可离线演示（仅作现场备用，**不能替代在线链接**）。

> 作业原文要求："仅提供本地运行地址（如 localhost）或代码仓库，不能代替在线体验链接。"
> 所以务必完成第 1 节或第 2 节，拿到真正的公网网址。
