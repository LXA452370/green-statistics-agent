# 绿账本 GreenLedger

**数据中心能效与碳排 · 数据清洗分析智能体**

上传一张机房电费 / 能耗 / PUE 台账（Excel 或 CSV），自动完成 **数据体检 → 清洗 → 指标计算 → 分析报告**，
并输出可下载的清洗后数据与 Markdown 报告。全部计算在浏览器本地完成，**数据不上传、不联网也能用**。

> 在线体验链接：**（部署后把网址填在这里）**
> 建议体验路径：首页 → 点「02 脏数据样例」→ 看体检 → 确认执行 → 生成报告（约 40 秒走完）

## 1. 它能做什么

| 步骤 | 你会看到 | 说明 |
| --- | --- | --- |
| ① 上传数据 | 拖入 .csv / .xlsx，或用内置示例 | 自动识别 UTF-8 / GBK 编码；取第一个工作表 |
| ② 体检与确认 | 0–100 数据健康分、问题清单、字段映射、清洗计划 | 计划可勾选，每条都写明"做什么 / 为什么" |
| ③ 执行清洗 | 保留行数、修正统计、改动明细（行号 + 标记）、清洗后预览 | 每一处改动都可追溯，可下载清洗后 CSV |
| ④ 分析报告 | PUE / 绿电占比 / 碳排 / 电费四张卡 + 三张图 + 七段式报告 | 报告可下载 Markdown、可打印成 PDF |

**七个可量化的能力点**

- 缺失、重复、单位混用（kWh / MWh）、日期多格式、站点名多写法 —— 自动识别并给出处理方案
- PUE 边界校验（1.0–3.0）与口径一致性校验（与"总能耗 ÷ IT 能耗"偏差 >5% 标记）
- 绿电占比 ≤ 100% 的逻辑校验、总能耗 < IT 能耗的冲突校验
- 排放因子可改（默认 0.5703 tCO₂/MWh，生态环境部全国电网平均因子 2022），报告注明来源
- 异常值只标记不删除，单独成表 —— 避免"洗掉真问题"
- 报告固定七段：结论 / 数据质量 / 能效 / 绿色化 / 异常清单 / 建议 / 口径与来源
- 可选接入大模型改写措辞（不接也能用；接口不通时用"复制提示词"粘贴到任意模型）

## 2. 怎么用（教师 3 步体验）

1. 打开链接，点 **「02 脏数据样例 · 152 行」** —— 这是主演示数据（含 5 类脏点）。
2. 在「体检与确认」页看健康分和问题清单，直接点 **「确认，执行清洗」**。
3. 在「分析报告」页看四张指标卡与三张图，点 **「下载 Markdown」** 或 **「打印 / 存为 PDF」**。

想验证"Excel 也能用"：回到首页，上传 `data/示例数据_脏台账.xlsx` 即可。
想验证"干净数据"：点「01 规范样例」。想验证"数据不足"：点「03 最小样例」（报告会老实说"无法计算 PUE"）。

## 5. 常见问题

- **提示"解析失败"**：确认是 .xlsx（不是旧版 .xls）；合并单元格请先取消合并；表头请保持单行。
- **中文乱码**：把文件另存为 "CSV UTF-8"；程序会自动再尝试 GBK。
- **日期解析反了（05/01/2025）**：程序对歧义日期按 M/D/Y 处理，并在清洗计划里注明；建议统一用 YYYY-MM-DD。
- **单位修正疑似误判**：单位修正基于"同列出现约 1000 倍差异"，修正行全部列在"改动明细"里，可人工复核。
- **AI 分析报跨域错误**：浏览器直连模型接口可能被拦截，点"复制提示词"粘贴到 Coze / 任意大模型即可。
- **本地打开（file://）**：直接双击 index.html 也能用，无需服务器。
