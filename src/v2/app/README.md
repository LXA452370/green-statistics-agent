# 统计分析助手 v2.0

**上传一张 Excel → 大模型决定"算哪些指标" → 代码把数字算准 → 左边出结果、右边出建议。**

纯前端网页，零运行时依赖，数据不出浏览器。

---

## 1. 三步用起来

| 步骤 | 你做什么 | 页面做什么 |
| --- | --- | --- |
| ① 上传 | 拖入 `.xlsx` / `.csv`，或点 5 份内置数据 | 识别每列类型（数值/类别/标识）、清洗（去空格、全角转半角、文本转数字、去重） |
| ② 定计划 | 复制提示词给大模型，把 JSON 粘回来；或直接「用默认计划」 | 拼提示词 → 白名单校验（不存在的列一律丢弃）→ 显示"要算哪些指标" |
| ③ 看结果 | 左窗口看表和图，右窗口看建议 | 代码算描述统计/分组/相关/直方图；规则提示 + 大模型解读 |

## 2. 两个窗口的分工

- **窗口 A · 统计结果**：全部由代码计算。均值、中位数、标准差、方差、最值、极差、Q1/Q3、CV、偏度、峰度、95% 置信区间、异常值、分组比较（含效应量 d）、Pearson 相关、直方图、频数。
- **窗口 B · 分析建议**：规则提示（确定性，必然有）+ 大模型解读（可选）。

> 原则：**统计交给代码，防止幻觉；分析交给大模型，负责说人话。**

## 3. 大模型怎么接（四种方式）

1. **复制粘贴（推荐先试）**：点「复制规划提示词」→ 粘到任意大模型网页 → 把回复粘回页面。
2. **浏览器直连**：右上角「大模型设置」填接口地址 / 模型 / Key，点「直接调用」。可能遇到跨域限制。
3. **本地代理**：跑一个 20 行的 Python 代理，Key 留在后端。
4. **云函数代理**：把代理放云函数，Key 配环境变量，部署后公网可用。

详细步骤、代码、各家接口地址与安全清单，见 `大模型接入方案.md`。

## 6. 口径声明

- 样本方差用 **n−1**；标准差 = √方差。
- 变异系数 CV = 标准差 ÷ |均值|。
- 四分位用线性插值；异常值按 **1.5×IQR** 判定，只标记不删除。
- 缺失值**不做填充**（避免编造），统计时按列剔除，每个指标单独标注有效样本量。
- 相关系数为 Pearson r，附样本量与显著性近似判断；**相关不等于因果**。
- 组间差异用效应量 d =（最高组均值 − 最低组均值）÷ 合并标准差。

## 7. 本地打开与部署

- **单文件版**：`第二版_单文件版.html`，双击即用，也能拖到任意位置。
- **完整版**：本文件夹整体移动；只拖 `index.html` 会丢样式（相对路径失效）。
- **部署**：把本文件夹（或 `第二版_部署包.zip`）拖到 Cloudflare Pages / Netlify，得到公网链接。
