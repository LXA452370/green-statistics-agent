# 经管数据统计分析 v6.0

导入 Excel → 选择模式（专业 / 简单）→ 程序计算 → 图表与统计表；模型可选，未接入时不做任何分析结论。

纯前端，无后端依赖；数据在本地解析。

## 2. 两种模式

### 专业模式
勾选多个数值变量，自选分组变量、分组指标、分布图变量与是否相关；输出描述统计、组间比较、相关分析、四幅图（含相关矩阵）。

### 简单模式
只选一个**主分析变量**：
- 描述统计只算它；
- 分组比较用它（分组变量可选）；
- 相关系数只算它与其余数值变量（可关闭）；
- 图表聚焦它（直方图、组均值、它与最强相关变量的散点），不画矩阵。

适合“只想看某一门课成绩”的老师或非统计背景使用者。

## 3. 导出格式

下载 `统计分析结果.txt`，结构固定：

```
统计分析结果
数据文件：…    有效样本：…    统计变量：… 个    主分析：…（简单模式才有）
【基本信息】变量范围 / 缺失处理 / 分组变量
【方差与离散程度】每个变量一行：方差、标准差、变异系数
【均值与位置】每个变量一行：均值、中位数、极值、偏度、离群值
【相关系数】每对一行：r、n、是否显著
【分组均值】每组一行：均值、n、标准差
【模型建议】（有则输出）
口径说明
```

表格只留在网页上，导出文本便于贴进 Word 或直接读。

## 4. 模型（可选）

1. 右上角「模型设置」→ 展开「怎么接入：四步」，按提示创建密钥；
2. 接口地址 `https://api.deepseek.com/v1`，模型 `deepseek-chat`；
3. 测试连接 → 保存；
4. 第二步「模型推荐方案」，第三步「生成建议」；
5. 提示词会带上主分析变量，模型只会围绕它给建议。

未接入模型时，结果页固定声明“不生成任何分析结论或建议”。

## 5. 统计口径

样本方差 n−1；缺失不插补、按变量剔除；离群值 1.5×IQR 仅标记；Pearson r；组间比较用效应量 d。
