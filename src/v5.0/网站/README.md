# 经管数据统计分析 v5.0

导入 Excel → 自选变量 → 程序计算 → 图表与统计表；模型建议置于页首，未接入时明确声明不生成任何分析结论。

纯前端，无后端依赖；数据在本地解析。

---

## 1. 三步

| 步骤 | 内容 |
| --- | --- |
| 1 导入数据 | .xlsx / .csv，首行为变量名；本地解析，不上传 |
| 2 分析计划 | 自选数值变量、分组变量、分布图变量、是否相关；计划与提示词实时更新 |
| 3 统计结果 | 分析建议（置顶）→ 四幅图 → 描述统计 / 相关分析 / 分组统计 |

## 2. 两套配色（单文件版）

## 3. 变量自选

- 数值变量多选（默认全选，最多 6 个）；未选变量不参与任何计算。
- 分组变量仅列出取值 2–10 类的分类变量。
- 相关分析可关闭；变量少于 2 个时自动禁用。

## 4. 结果呈现

- 图表：分布直方图、组均值（±1 SD）、散点与拟合线、相关系数矩阵。
- 分组超过 6 组自动省略误差线与柱顶数值；矩阵长变量名改用 V1…Vn 并附图例。
- 统计表：描述统计（每行一个变量）、相关分析（每行一对）、分组统计（每组一行）。
- 未接入模型时，页首固定声明“不生成任何分析结论或建议，仅提供统计结果与图形”。

## 5. 模型

1. 右上角「模型设置」填写接口地址、模型名、API Key，测试连接后保存。
2. 第二步「模型推荐方案」；第三步「生成建议」。
3. 被跨域拦截时用「复制提示词」到其他平台生成后粘贴回来。

## 6. 统计口径

样本方差 n−1；CV = SD ÷ |均值|；离群值 1.5×IQR 仅标记；缺失不插补；Pearson r（显著性 |r| > 1.96/√(n−2) 近似）；组间用效应量 d。
