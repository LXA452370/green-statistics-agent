# 经管数据统计分析 v4.0

**导入 Excel → 自选分析变量 → 程序计算 → 图形与统计表；需要解释时再调用模型。**

纯前端，无后端依赖；数据在本地解析。

---

## 1. 三步

| 步骤 | 内容 | 说明 |
| --- | --- | --- |
| 1 导入数据 | .xlsx / .csv | 首行为变量名；本地解析，不上传 |
| 2 分析计划 | 自选数值变量、分组变量、分布图变量、是否相关 | 计划预览与提示词随设置实时更新 |
| 3 统计结果 | 图表 → 描述统计 → 相关分析 → 分组统计 | 不输出内置结论；模型建议为可选项 |

## 2. 变量自选

- **数值变量**：多选，默认全选（最多 6 个）；未选中的变量不参与任何计算。
- **分组变量**：仅列出取值 2–10 类的分类变量，学号、姓名等高基数字段不出现。
- **分组比较指标 / 分布图变量**：只能从已选数值变量中选择。
- **相关分析**：开关控制；变量少于 2 个时自动禁用。

> 这样做的目的：不是每份数据都需要相关分析，也不是每个分类变量都适合分组比较。

## 3. 结果呈现

- **图表**：分布直方图（含均值线）、组均值（±1 个标准差）、散点与最小二乘拟合、相关系数矩阵。
- **分组图**：超过 6 组自动省略误差线与柱顶数值，标签旋转；不超过 6 组保留误差线。
- **相关矩阵**：变量名较长时改用 V1…Vn，并在图下给出对照。
- **统计表**：描述统计（每行一个变量）、相关分析（每行一对变量）、分组统计（每组一行）。页面长度只随变量数与组数增长，不罗列样本。

## 4. 模型（可选）

1. 右上角「模型设置」填写接口地址、模型名、API Key，测试连接后保存。
2. 第二步「模型推荐方案」：在已选变量范围内给出方案建议，页面会映射回界面设置。
3. 第三步「生成建议」：基于已计算统计量输出业务建议与可执行方案。

未配置模型时，不使用任何模型能力，页面只呈现统计结果与图形。被跨域拦截时，用「复制提示词」到其他平台生成后粘贴回来。

## 5. 统计口径

- 样本方差取 **n−1**，标准差为方差平方根。
- 变异系数 **CV = SD ÷ |均值|**。
- 四分位用线性插值；离群值按 **1.5×IQR** 判定，仅标记不剔除。
- 缺失值**不作插补**，按变量剔除并标注有效样本量。
- Pearson r；显著性以 |r| > 1.96/√(n−2) 近似判断。
- 组间比较用效应量 **d**（≥0.80 为大效应）。
