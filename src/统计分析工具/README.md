# 经管数据统计分析 v3.0

**导入 Excel → 由模型或规则确定统计方案 → 程序计算 → 结论优先呈现。**

纯前端，无后端依赖；数据在本地解析。

---

## 1. 三步

| 步骤 | 内容 | 说明 |
| --- | --- | --- |
| 1 导入数据 | .xlsx / .csv | 首行为变量名；本地解析，不上传 |
| 2 分析计划 | 变量清单 + 统计方案 | 方案来源三选一：模型直连 / 复制提示词 / 默认方案 |
| 3 统计结果 | 结论 → 关键指标 → 4 幅图 → 折叠的完整统计量 | 结论置顶；完整数据按需展开 |

## 2. 结论优先的版面

- **结论**：规则结论（必出，可复现）；模型解读（可选，调用模型生成）。
- **关键指标**：3 个变量的均值、标准差、变异系数与离散判定，另附组间效应量与最强相关。
- **四幅图**：分布直方图、组均值与标准差、散点与拟合线、相关系数矩阵。
- **完整统计结果**：14 项描述统计、分组明细、相关系数、频数，默认折叠。

## 3. 模型接入

1. 右上角「模型设置」填写接口地址（如 `https://api.deepseek.com/v1`）、模型名、API Key。
2. 点「测试连接」，返回正常后保存。
3. 第二步「模型直连」生成分析计划；第三步「生成模型解读」。

若厂商不允许浏览器跨域调用，改用「复制提示词」：复制后到任意对话式模型平台获取结果，再粘贴回填。详细排查见根目录《方案B_浏览器直连大模型_说明.docx》。

> 密钥仅保存在本机浏览器（localStorage），不写入页面源码。提交材料前请清空。

## 4. 统计口径

- 样本方差取 **n−1**，标准差为方差平方根。
- 变异系数 **CV = SD ÷ |均值|**，判定阈值：≥0.30 偏高、0.20–0.30 中等、<0.05 高度集中。
- 四分位用线性插值；离群值按 **1.5×IQR** 判定，仅标记不剔除。
- 缺失值**不作插补**，按变量剔除并标注有效样本量。
- 相关系数为 **Pearson r**，显著性以 |r| > 1.96/√(n−2) 近似判断；相关不等同于因果。
- 组间比较用效应量 **d =（最高组均值 − 最低组均值）÷ 合并标准差**，≥0.80 为大效应。

## 5. 目录

```
统计分析工具/
├─ index.html            页面（三步）
├─ assets/
│  ├─ style.css          版式与配色（墨绿 / 黄铜 / 暖纸）
│  ├─ stat-engine.js     统计引擎（画像、清洗、计划校验、计算、结论、提示词）
│  ├─ app.js             交互层（导入、方案、四幅图、导出、模型直连）
│  ├─ xlsx-lite.js       零依赖 xlsx 读取
│  └─ samples.js         5 份示例数据
└─ data/                 5 份 csv + xlsx
```

## 6. 5 份示例数据

| 文件 | 用途 |
| --- | --- |
| 01_学生成绩_干净 | 变异系数 0.32；班级组间差异显著；三变量相关 |
| 02_学生成绩_脏数据 | 缺失、重复、文本型缺失、离群值；演示均值受极端值影响 |
| 03_门店销售 | 销售额与客流量高度相关；地区差异 |
| 04_员工绩效 | 培训时长与绩效正相关；部门差异有限 |
| 05_季度经营 | 小样本；单季亏损；结构性相关 |

## 7. 本地与部署

- 单文件版：`第三版_单文件版.html`，双击即用。
- 完整版：整体移动本目录；单独拖出 `index.html` 会因相对路径失效而丢样式。
- 部署：将本目录或 `第三版_部署包.zip` 上传至 Cloudflare Pages / Netlify，得到公网地址。
