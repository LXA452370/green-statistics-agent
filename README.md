# 经管数据统计分析智能体

> 统计交给代码，分析交给大模型。导入 Excel，选好变量，程序完成描述统计、组间比较、相关分析与四幅图；模型仅提供方案建议与文字解读，不参与数值计算。

纯前端静态网页，无后端依赖；数据在浏览器本地解析。

## 目录

```
src/
├─ v1/  绿账本：能耗数据清洗        app/ · single-file.html · deliverables/ · notes.txt
├─ v2/  统计分析：三步流程与模型计划  app/ · single-file.html
├─ v3/  结论优先：四幅图与模型直连    app/ · single-file.html
├─ v4/  变量自选：判断权交回使用者    app/ · single-file.html
├─ v5/  细节收口：建议置顶与两套配色  app/ · single-file-01.html · single-file-02.html
└─ v6/  双模式与纯文本导出（当前）    app/ · single-file.html

docs/     各版本的说明与截图快照（v1–v6）
reports/  交付文档：设计报告、开发步骤、使用手册
```

- `app/`：该版本的多文件版源码，入口是 `index.html`。
- `single-file*.html`：该版本的单文件版，双击即用。
- 六个版本与标签一一对应：`git checkout v3.0` 可回到第三版当时的完整状态。

## 当前版本 v6

- **双模式**：专业模式多选变量、出四图与相关矩阵；简单模式只选一个主分析变量，其余变量仅作相关对照。
- **纯文本导出**：一行一个指标（方差、均值、相关系数、分组均值），不导出表格。
- **导入页**：只强调“仅支持 xlsx/csv、首行必须是变量名”，口径与模型说明分两条。
- **接入向导**：模型设置内附四步说明，密钥只存本机。
- **配色**：墨绿 + 黄铜 + 暖纸，全版本统一。

## 快速开始

新手直接双击：`src/v6/single-file.html`。

看源码：`src/v6/app/index.html`（需与 `assets/`、`data/` 同目录）。
示例数据在 `src/v6/app/data/01–05`（csv 与 xlsx 各一份）。

## 统计口径

样本方差 n−1；缺失不插补、按变量剔除；离群值 1.5×IQR 仅标记；Pearson r；组间比较用效应量 d。
