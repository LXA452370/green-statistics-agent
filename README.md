# 经管数据统计分析智能体

> 统计交给代码，分析交给大模型。导入 Excel，自选变量，程序完成描述统计、组间比较、相关分析与四幅图；模型仅提供方案建议与文字解读，不参与数值计算。

## 当前版本：v2.0

换成通用统计场景：导入 → 分析计划 → 结果；模型只输出 JSON 计划，程序负责计算。

## 快速开始

1. 打开 `src/统计分析工具/index.html`（或单文件版）。
2. 点示例数据，勾选变量，执行分析。
3. 结果页查看图表与统计表，可导出 Markdown。

## 目录

```
src/    程序与示例数据
docs/   说明、截图与报告
```

## 版本历史

- `v1.0` v1 绿账本：能耗数据清洗（内部验证）
- `v2.0` v2 统计分析：三步流程与模型出计划

## 统计口径

样本方差 n−1；缺失不插补、按变量剔除；离群值 1.5×IQR 仅标记；Pearson r；组间比较用效应量 d。
