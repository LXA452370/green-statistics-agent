# 大模型接入方案（网页里到底怎么用上大模型）

> 适用作品：第二版「统计分析助手」
> 一句话原则：**统计交给代码（防幻觉），分析交给大模型（好表达）；两者之间用 JSON 传话。**

---

## 0. 先搞清"接大模型"到底接的是什么

大模型不是一个装在电脑里的软件，而是**别人服务器上的一个接口**。你的网页要"用上它"，本质上就是：
**把你的文字（提示词）通过网址发过去，再把它的回复拿回来。**

这件事叫**调用 API**，请求长这样（所有厂商大同小异）：

```
POST https://api.deepseek.com/v1/chat/completions
Authorization: Bearer sk-你的密钥
{"model":"deepseek-chat","messages":[{"role":"user","content":"你的提示词"}]}
```

返回里就是一段文字。我们要做的，只是把这段文字**塞进页面的某个位置**。

### 为什么会有"跨域"这个坑

浏览器有一条安全规则叫**同源策略**：`你的网页` 和 `大模型的服务器` 不是同一个来源，浏览器默认**不让网页直接读对方的返回**（这就是 CORS 限制）。
- 有的厂商允许浏览器直连（会返回 `Access-Control-Allow-Origin: *`）；
- 有的不允许，控制台会报 `blocked by CORS policy`。

所以下面给了 4 种方案，**按"是否需要解决跨域"和"是否要花钱/注册"排列**。

---

## 方案 A（推荐先用）：复制粘贴，零配置

**做法**：页面把提示词生成好 → 你复制 → 粘到任意大模型网页（DeepSeek / 豆包 / Kimi / ChatGPT 都行）→ 把它回复的 JSON 粘回页面。

**步骤**
1. 第二步页面点「复制规划提示词」；
2. 打开 DeepSeek 网页，粘贴，发送；
3. 复制它返回的 JSON（哪怕前后带了解释文字也没关系，页面会自动截取 `{...}`）；
4. 回到页面，粘贴到"把大模型的回复粘回来"框，点「解析并应用」。

**优点**：不用 Key、不花钱、不受跨域影响、课堂演示最稳。
**缺点**：多两次复制粘贴，不能"一键"。

> 这一步恰好也证明了"大模型只定计划、不碰数字"——你可以当场问它"算一下均值"，它会算错，而页面里的数字永远是对的。

---

## 方案 B：浏览器直连（填 Key，一键调用）

页面已经内置了这个能力：
右上角「大模型设置」→ 填 **接口地址 / 模型名 / API Key** → 保存。
之后第二步、第三步会出现「直接调用大模型」按钮。

**常见厂商填法（OpenAI 兼容）**

| 厂商 | 接口地址 | 模型名示例 |
| --- | --- | --- |
| DeepSeek | `https://api.deepseek.com/v1` | `deepseek-chat` |
| 月之暗面 Kimi | `https://api.moonshot.cn/v1` | `moonshot-v1-8k` |
| 阿里通义（兼容模式） | `https://dashscope.aliyuncs.com/compatible-mode/v1` | `qwen-plus` |
| OpenAI | `https://api.openai.com/v1` | `gpt-4o-mini` |

（地址栏填到 `/v1` 即可，页面会自动补 `/chat/completions`。）

**Key 存在哪**：只存在你**本机浏览器**的 `localStorage`，不会上传到任何地方，也不会写进代码。

**必须知道的三个风险**
1. **跨域可能被拦**：报 `CORS` 就改用方案 A 或 C，不要反复重试。
2. **Key 等于钱**：泄露了别人能拿去消耗你的额度。**绝不能**把 Key 写进 HTML、截图、报告或提交材料。
3. **别用主账号**：建议单独建一个 Key，设好额度上限，用完就删。

## 方案 C：本地代理（解决跨域，Key 留在后端）

思路：网页只请求**你自己电脑上的小程序**，由它去请求大模型。这样浏览器同源，不报跨域；Key 也只在你电脑上。

**`proxy.py`（约 20 行，放在任意文件夹）**

```python
# pip install flask flask-cors requests
from flask import Flask, request, jsonify
from flask_cors import CORS
import requests, os

app = Flask(__name__)
CORS(app)                      # 允许网页跨域调用本代理
API_KEY = os.environ.get("LLM_KEY", "")   # 建议用环境变量，不要写死在代码里
BASE = "https://api.deepseek.com/v1"

@app.post("/v1/chat/completions")
def chat():
    r = requests.post(BASE + "/chat/completions",
                      headers={"Authorization": "Bearer " + API_KEY},
                      json=request.get_json(), timeout=60)
    return (r.content, r.status_code, {"Content-Type": "application/json"})

if __name__ == "__main__":
    app.run(port=8000)
```

**运行**（Windows PowerShell）：
```powershell
$env:LLM_KEY="sk-你的密钥"
python proxy.py
```
然后在页面「大模型设置」里，接口地址填 `http://127.0.0.1:8000/v1`，模型名照常填，Key 可以随便填一个占位（真正的 Key 在代理里）。

**优点**：彻底绕开跨域；Key 不暴露给浏览器；可以顺手加日志、限流。
**缺点**：演示时电脑上要多跑一个程序；不能部署成纯静态网站（除非上云函数，见方案 D）。

## 方案 D：云函数代理（部署到公网也能用）

把方案 C 的代码搬到**腾讯云函数 / 阿里云函数计算 / Cloudflare Workers**：
- Key 配成云函数的**环境变量**（不要写在代码里）；
- 得到一个公网 HTTPS 地址；
- 页面「接口地址」填它即可。

Cloudflare Workers 片段（最省事）：
```js
export default {
  async fetch(req, env) {
    const body = await req.text();
    const r = await fetch("https://api.deepseek.com/v1/chat/completions", {
      method: "POST",
      headers: { "Content-Type": "application/json", "Authorization": "Bearer " + env.LLM_KEY },
      body
    });
    return new Response(r.body, { headers: { "Access-Control-Allow-Origin": "*", "Content-Type": "application/json" } });
  }
}
```
（记得在 Worker 设置里加 `LLM_KEY` 环境变量。）

## 方案 E：平台化（Coze / Dify 工作流版）

如果老师更认"平台作品"，可以把同样的逻辑搬到 Coze 工作流：

1. **开始节点**：文件变量（上传 Excel）；
2. **代码节点**：用 Python 读表、算统计（把 `stat-engine.js` 的公式照抄成 Python 即可）；
3. **大模型节点**：输入 = 统计结果 JSON，提示词 = 本项目的"建议提示词"；
4. **结束节点**：输出"统计表 + 建议"。

发布后拿到网页链接即可。注意：平台的代码节点可能没有 pandas，需要先用平台自带的表格解析插件。

## 该选哪个？一张表决定

| 场景 | 推荐 | 理由 |
| --- | --- | --- |
| 课堂/答辩现场演示 | **A 复制粘贴** | 零配置、不怕断网限流、翻车概率最低 |
| 想展示"一键自动化" | B 直连 | 体验最好，但要先测通跨域 |
| 要长期给同学用、又怕 Key 泄露 | C/D 代理 | Key 在服务端，前端干净 |
| 老师要求"平台作品" | E Coze | 有平台链接、有工作流截图 |

**最稳的组合**：A 做保底 + B 做亮点（演示时先走 A，成功后再点一次 B）。

## 三段可以直接用的提示词（已内置在页面里）

1. **规划提示词**：把列信息、前 4 行样例、5 个允许的统计动作给模型，要求它只输出 JSON，并列名必须完全一致。
2. **建议提示词**：把"已经算好的统计结果 JSON"给模型，要求每条建议引用具体数字、禁止估算、相关不许写成因果。
3. **兜底策略**：模型返回的 JSON 会被**白名单校验**——不存在的列、非法的动作一律丢弃，并回退到默认计划。这样即使模型胡说，页面也不会崩。

## 演示话术（30 秒版）

> "这一页分两步用到大模型：第一步它只做'选题'——看数据结构，决定算哪些指标，输出一段 JSON；第二步它只做'表达'——拿着代码算好的数字写建议。
> 所有数字都来自代码，所以同一份数据跑两次结果完全一样；大模型就算想编，也编不进表格里。
> 您看这个班数学的变异系数是 0.32，页面提示'两极分化'，这条判断是规则算出来的，不是模型感觉出来的。"
