# 文档索引

每个版本目录对应一个 tag，存放该版本当时的界面截图与说明材料，和 `src/` 下的同名目录配套。

| 目录 | 内容 | 说明 |
| --- | --- | --- |
| [v1.0](v1.0/) | 2 张故障对比图、说明材料 | 能耗数据清洗阶段 |
| [v2.0](v2.0/) | 5 张截图、大模型接入方案、测试记录 | 三步流程与模型出计划 |
| [v3.0](v3.0/) | 5 张截图 | 结论优先与四幅图 |
| [v4.0](v4.0/) | 5 张截图 | 变量自选与图表防重叠 |
| [v5.0](v5.0/) | 3 张截图 + 配色示意 | 建议置顶与两套配色 |
| [v6.0](v6.0/) | 6 张截图 | 双模式、纯文本导出、接入向导 |

## 与其他目录的关系

- 程序在 `src/v1.0–v6.0/`，本目录只放截图与文字说明。
- 交付文档（设计报告、开发步骤、使用手册）保存在本地，不放进仓库，避免与版本快照混在一起。
- 历史快照也可用标签查看：`git checkout v3.0`。

## 命名

目录名与标签一致；截图保留原始文件名，便于与网页对照。
