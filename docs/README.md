# 文档索引

每个 `vN/` 对应一个版本快照，内容是该版本当时的说明与截图，和 `src/vN/` 的程序配套。

| 目录 | 内容 | 说明 |
| --- | --- | --- |
| [v1](v1/) | 绿账本原理详解、2 张故障对比图 | 能耗数据清洗阶段 |
| [v2](v2/) | 第二版说明、大模型接入方案、测试记录、5 张截图 | 三步流程与模型出计划 |
| [v3](v3/) | 第三版说明、5 张截图 | 结论优先与四幅图 |
| [v4](v4/) | 第四版说明、5 张截图 | 变量自选与图表防重叠 |
| [v5](v5/) | 4 张界面与配色截图 | 建议置顶与两套配色 |
| [v6](v6/) | 6 张截图 | 双模式、纯文本导出、接入向导（说明文档待补） |

## 与其他目录的关系

- 程序在 `src/vN/`，本目录只放说明与截图。
- 交付文档在 `reports/`，不放版本快照里，避免反复更新时和归档混在一起。
- 历史快照也可用标签查看：`git checkout v3.0`。

## 命名

目录名与标签一致（`v1` ↔ `v1.0`），截图保留原始文件名，便于与网页对照。
