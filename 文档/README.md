## 与其他目录的关系

- 程序在 `程序/第一版–第六版/`，本目录只放说明与截图。
- 交付文档不放进仓库，避免与版本快照混在一起。
- 历史快照也可用标签查看：`git checkout v3.0`。

## 命名

目录名与版本对应（第一版 ↔ `v1.0`）；截图保留原始文件名，便于与网页对照。
